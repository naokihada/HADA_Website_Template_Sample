# Cursor workspace

Agent workspace for tasks, reports, logs, and state. **Not part of Publication Root.**

Do not deploy this directory to the web server.

| Path | Role |
|---|---|
| `tasks/` | TODO, CURRENT, BACKLOG |
| `reports/` | Analysis, test, security, release reports |
| `logs/` | Operational logs |
| `inventory/` | File and asset inventories |
| `changelog/` | Change history notes |
| `state/` | Persistent agent/session state |
| `backup/` | Pre-change backups |
| `screenshots/` | Visual verification captures |

See `AGENTS.md` for logging and reporting rules.
